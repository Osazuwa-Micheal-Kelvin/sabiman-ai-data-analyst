# Security Policy

## What this repository contains
- Documentation, screenshots and exported n8n workflows for SABIMAN AI.
- Credentials, API keys and sample datasets have been removed from the workflow exports.

## Before you run these workflows
- Add your **own** API credentials in n8n. Never paste keys into workflow JSON or commit them to a repository.
- Use dedicated, limited-permission API keys.
- Review the workflow and test with non-sensitive data first.
- Avoid uploading confidential or personal data to any instance you do not control.

## Reporting a problem
If you find a leaked credential, private data, or a security issue, please email **[your-email]** with the subject "Security: sabiman-ai-data-analyst". Please do not open a public issue for sensitive findings.
